Programme-standard weights, expanded into Day 6–specific observable criteria. `scripts/grade.mjs` scores everything except Presentation (marked by hand from the learner's `NOTES.md` entries) — it prints a total out of 85 and Presentation is added on top by the trainer, out of 15, for 100 overall.

| Criterion | Weight | Full marks | Partial marks | Zero marks |
|---|---|---|---|---|
| **Functionality** | 30 | All three of `.claude/agents/security-reviewer.md`, `perf-reviewer.md`, `style-reviewer.md` exist with valid YAML frontmatter (`name`, `description`, `tools`); every one of the three scopes `tools` to exactly `Read`/`Grep`/`Glob` (no `Write`, `Edit`, or `Bash`); `.mcp.json` exists at the repo root, is valid JSON, and registers at least one server under `mcpServers`. | One or two agent files present/valid rather than all three; one agent's `tools` list includes something outside `Read`/`Grep`/`Glob` while the others are correctly scoped; `.mcp.json` exists and is valid JSON but `mcpServers` is empty or missing. | No agent files under `.claude/agents/`, or none parse as valid frontmatter; an agent grants `Write`, `Edit`, or `Bash`; no `.mcp.json`, or it isn't valid JSON. |

| **Best practices** | 10 | No new dependencies added to `package.json` beyond Day 6's baseline — this exercise is achievable with what's already installed; the populated plugin directories contain the actual expected content copied from this repo's own `.claude/` (the same three reviewer agent names, the Day 4 commands, the `api-endpoint` skill) rather than placeholder or unrelated files. | A new dev-only dependency was added that wasn't strictly necessary; the plugin directories contain some real content but it doesn't match what this repo's own `.claude/commands`/`.claude/skills`/`.claude/agents` actually has (e.g. only one command copied, or agent names in the plugin don't match the three built in Block 2). | A new runtime dependency was added; the plugin directories contain filler/unrelated content instead of the real commands, skill, and agents this repo already has. |

**Scoring note for the trainer**: `scripts/grade.mjs` prints a per-criterion table with points earned out of 30/25/20/10 (Functionality, Tool usage, Code quality, Best practices — Presentation is excluded from its total) and a combined total out of 85. Add your hand-scored Presentation mark (0–15) to get the final mark out of 100. The programme pass mark is 60/100 overall; the script itself exits non-zero below 60/85 on its own scope as an early warning, but the authoritative pass/fail decision is the full 100-point total including your Presentation mark.

**Validated against the starting state**: this grader is checked to score low and exit non-zero against Day 6's unmodified starting state (no `.claude/agents/`, no `.mcp.json`, no `reports/review.md`, plugin directories still holding only their placeholder `README.md`) — if it doesn't, the grader itself is broken and its score should not be trusted.
